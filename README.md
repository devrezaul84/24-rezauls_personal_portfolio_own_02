## Run locally
Open `index.html` in a browser. For a local development server, use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `rezaul-karim-portfolio`.
2. Upload the contents of this folder (not the parent folder) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After GitHub Pages finishes deploying, use the URL shown in the Pages section.

Expected URL format (the actual URL appears after deployment):
`https://devrezaul.github.io/rezaul-karim-portfolio/`
